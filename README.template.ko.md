## 이미지 투 비디오 파이프라인

```
1. First frame   → Qwen Image 2.1 (photoreal, from $0.024) or Qwen Image 2.1 LoRA + an anime LoRA (anime)
2. Fix details   → Qwen Image Edit Spicy (change outfit, pose, lighting with one instruction)
3. Draft motion  → Wan 2.6 Flash, Seedance 1.5 Pro Spicy or Wan 2.2 Spicy at 480p, 3–5 variations
4. Final render  → the best draft's prompt on Wan 3.0, Seedance 2.5 Spicy or Wan 2.7 Spicy at 720p–1080p
5. Extend        → Wan 2.2 Spicy LoRA video-extend, or last-frame chaining
6. Polish        → Video Upscaler, Lip Sync or Video Sound Effects
```

이 방식으로 만드는 일반적인 5초 클립의 비용은 약 **$0.024(첫 프레임) + $0.29(480p Wan 2.2 Spicy 초안 3개) + $0.45(720p Wan 3.0 최종본 1개) ≈ $0.76**입니다.

**코드 없이:** 원하는 프롬프트를 [SpicyAPI Studio › 이미지 투 비디오](https://spicyapi.ai/ko/create/image-to-video?utm_source=github&utm_medium=repo&utm_campaign=2026-09-nsfw-ai-video-prompts&utm_content=run-ko) 또는 [무검열 AI 영상 생성기](https://spicyapi.ai/ko/create/uncensored-ai-video-generator?utm_source=github&utm_medium=repo&utm_campaign=2026-09-nsfw-ai-video-prompts&utm_content=run-ko)에 붙여 넣고, 첫 프레임을 업로드한 뒤, 생성 전에 가격을 확인하세요.

**cURL:**

```bash
      "duration_seconds": 5,
      "resolution": "720p"
    }
  }'

# data.state가 "succeeded"가 될 때까지 폴링한 뒤 data.output.assets[0].url을 다운로드

  -H "Authorization: Bearer $SPICY_API_KEY"
```

**Python (표준 라이브러리만 사용):**

```python
import json, os, time, urllib.request, uuid

API = "https://api.spicyapi.ai/api/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['SPICY_API_KEY']}", "Content-Type": "application/json"}

def call(method, path, body=None, extra_headers=None):
    req = urllib.request.Request(API + path, method=method, headers={**HEADERS, **(extra_headers or {})},
                                 data=json.dumps(body).encode() if body else None)
    with urllib.request.urlopen(req) as resp:
        return json.load(resp)["data"]

task = call("POST", "/jobs/createTask", {
    "model": "alibaba/wan-2.2-spicy/image-to-video",
    "input": {"image_url": "https://example.com/first-frame.jpg",
              "prompt": "She turns slowly toward the camera, silk robe slipping off one shoulder, candlelight, slow push-in.",
              "duration_seconds": 5, "resolution": "480p"},
}, {"Idempotency-Key": str(uuid.uuid4())})

while task["state"] in ("queued", "running"):
    time.sleep(5)
    task = call("GET", f"/jobs/recordInfo?taskId={task['taskId']}")

print(task["state"], task.get("output", {}).get("assets", [{}])[0].get("url"))
```

## 자주 묻는 질문 (FAQ)

### Wan 2.2에 가장 좋은 NSFW AI 영상 프롬프트는?
이름이 붙은 카메라 무빙이 들어간 짧은 단일 동작 프롬프트입니다. [부두아 & 란제리](#부두아--란제리)와 [재사용 가능한 모션 & 카메라 템플릿](#재사용-가능한-모션--카메라-템플릿)을 참고하세요. Wan 2.2 Spicy는 정확히 5초 또는 8초로 렌더링하므로 클립 하나에 동작 하나를 쓰고, 특정한 마지막 장면이 필요하면 `last_image_url`을 사용하세요.

### NSFW 이미지 투 비디오 프롬프트는 어떻게 쓰나요?
좋은 첫 프레임에서 시작한 다음 움직임만 묘사하세요. 주요 동작 하나, 보조 움직임 하나, 카메라, 조명이면 됩니다. 길이는 40–80단어로 유지하세요. [제대로 작동하는 NSFW 영상 프롬프트 작성법](#제대로-작동하는-nsfw-영상-프롬프트-작성법)을 참고하세요.

### NSFW 이미지 투 비디오에 가장 좋은 모델은?
SpicyAPI 테스트 기준으로, 비용 대비 전반적으로 가장 좋은 결과는 **Wan 3.0**(Index 76.5, Freedom 96, 노골적 테스트 프롬프트를 모두 렌더링, 720p 5초당 $0.45), 필터가 가장 적은 이미지 투 비디오는 **Seedance 2.5 Spicy**, **Wan 2.7 Spicy**, **Vidu Q3 Spicy**(Freedom 96.7–100), 나만의 스타일은 **MiniMax H3 LoRA**, 저예산은 **Wan 2.6 Flash**와 **Seedance 1.5 Pro Spicy**입니다. [SpicyAPI 리더보드](https://spicyapi.ai/ko/leaderboards?utm_source=github&utm_medium=repo&utm_campaign=2026-09-nsfw-ai-video-prompts&utm_content=faq-ko)에서 비교해 보세요.

### NSFW AI 영상에서 인체가 이상하게 나오는 이유는?
대개 클립 길이에 비해 움직임이 너무 많기 때문입니다. 5초로 줄이고, 동작을 하나로 줄이고, 손은 화면 밖에 두거나 편안하게 두고, 전신 샷은 옆이나 뒤 앵글을 쓰고, 2인 장면에는 더 강력한 모델(Seedance 2.x)을 쓰세요.

### 이 프롬프트를 Stable Diffusion이나 ComfyUI에서도 쓸 수 있나요?
네. 첫 프레임 프롬프트는 SDXL, Pony, Z-Image 워크플로 어디서든 작동하고, 영상 프롬프트는 ComfyUI에서 셀프 호스팅한 Wan 2.2에서 작동합니다. 로컬에서는 strength와 steps를 조정해야 할 수 있습니다.

### NSFW AI 영상 생성 비용은 얼마인가요?
SpicyAPI 기준({{READ_ON}} 카탈로그), 5초 클립은 $0.06(Seedance 1.5 Pro Spicy, 480p) 또는 $0.095(Wan 2.2 Spicy, 480p)부터 약 $5.40(Seedance 2.5 Spicy, 1080p)까지입니다. 위의 각 프롬프트에 개별 비용이 적혀 있습니다.

### 무료 NSFW 영상 프롬프트 생성기가 있나요?
위의 [LLM 시스템 프롬프트](#llm에게-프롬프트-맡기기)를 아무 채팅 모델에서나 쓰면 됩니다. Ollama나 LM Studio의 로컬 모델도 가능합니다.
