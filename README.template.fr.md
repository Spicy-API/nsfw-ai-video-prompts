## Comment écrire un prompt vidéo NSFW qui fonctionne

```
[Who: adult, age range, look] + [One main action] + [Secondary motion: hair, fabric, light]
+ [Setting] + [Lighting] + [Camera move] + [Style / film look]
```

| À faire | À éviter |
|---|---|
| « She slowly slides one strap off her shoulder and looks up at the camera. » | « Sexy woman being hot. » |
| Une seule action principale par clip de 5 secondes | Toute une chorégraphie dans un seul clip |
| Nommer la caméra : *slow push-in*, *static*, *orbit left* | « Cinematic camera » |
| Décrire les sources de lumière : *candlelight*, *window light*, *neon rim* | « Good lighting » |
| Indiquer un âge adulte : *in her 30s*, *adult man in his 40s* | Les descripteurs qui suggèrent la jeunesse |
| Laisser la première image porter la tenue et le décor | Redécrire tout ce que l'image montre déjà |

**Fiabilité des mouvements, du plus fiable au moins fiable :** respiration et clignement des yeux → cheveux et tissu dans le vent → eau, vapeur, fumée, flamme de bougie → rotation lente de la tête, regard par-dessus l'épaule → marche vers la caméra ou s'en éloignant → étirement, se retourner → danse → contact entre deux personnes → action rapide ou acrobatique.

## Aide-mémoire caméra, lumière et mouvement

**Mouvements de caméra**

| Terme | Effet | Fiabilité |
|---|---|---|
| `static camera` / `locked-off` | La caméra ne bouge pas | Maximale |
| `slow push-in` | Avance vers le sujet | Élevée |
| `pull back` / `dolly out` | Recule et dévoile la pièce | Élevée |
| `tilt up` / `tilt down` | Pivote verticalement le long du corps | Élevée |
| `tracking shot` | Suit le sujet latéralement | Moyenne |
| `orbit left / right` | Tourne autour du sujet | Moyenne (meilleure sur Seedance) |
| `handheld` | Léger tremblé naturel, rendu de vidéo de créateur | Moyenne |
| `rack focus` | La mise au point passe du premier plan au sujet | Moyenne |
| `drone descent` / `drone pull-back` | Mouvement ample, en hauteur | Moyenne |
| `POV` | Vue à la première personne | Plus faible |

**Lumière selon l'ambiance**

| Ambiance | À écrire |
|---|---|
| Romantique | warm candlelight, golden tones, soft diffused light |
| Dramatique | single hard key light, deep shadows, chiaroscuro |
| Éthérée | backlit, glowing highlights, haze, bloom |
| Noir | slatted blinds light, black and white, cigarette smoke |
| Luxe | soft beauty lighting, no harsh shadows, glossy highlights |
| Mystérieuse | rim light only, face in shadow, silhouette |
| Naturelle | window light, golden hour, soft ambient |
| Néon | magenta and cyan neon, wet reflections, rain |

**Guide des durées**

| Contenu | Durée | Pourquoi |
|---|---|---|
| Respiration, cinemagraph | 4–5 s | Un mouvement minimal préserve la qualité |
| Un geste ou une rotation de la tête | 5 s | Une seule action claire |
| Marche, dévoilement, trajet de caméra | 5–8 s | Mouvement continu mais simple |
| Danse, scènes à deux | 5 s | Les clips plus longs accumulent les artefacts |
| Scènes plus longues | Prolonger par étapes | Utiliser `video-extend` ou enchaîner par la dernière image |

- **Seedance 2.5 / Seedance 2.0 / Wan 3.0 (standard, unrestricted)** : à utiliser pour le texte en vidéo ou la vidéo à partir de références (placer votre personnage de `@Image1` dans une nouvelle scène). - **LTX 2.3 Spicy** (à partir de $0.019/s) : 3 à 20 secondes par appel, prompt facultatif. Bien pour les plans longs et calmes ; le niveau le plus élevé est plus souvent adouci que sur Wan Spicy.

- **Wan 2.6 Spicy / Wan 2.7 Spicy** : acceptent `negative_prompt` et votre propre `audio_url` ; Wan 2.6 propose `shot_type` pour le multi-plans, Wan 2.7 peut générer l'audio.

## Le pipeline image en vidéo

```
1. Première image    → Qwen Image 2.1 (photoréaliste, à partir de $0.024) ou Qwen Image 2.1 LoRA + une LoRA anime (anime)
2. Corriger          → Qwen Image Edit Spicy (changer tenue, pose, éclairage en une instruction)
3. Brouillons        → Wan 2.6 Flash, Seedance 1.5 Pro Spicy ou Wan 2.2 Spicy en 480p, 3 à 5 variantes
4. Rendu final       → le prompt du meilleur brouillon sur Wan 3.0, Seedance 2.5 Spicy ou Wan 2.7 Spicy en 720p–1080p
5. Prolonger         → video-extend de Wan 2.2 Spicy LoRA, ou enchaînement par la dernière image
6. Finitions         → Video Upscaler, Lip Sync ou Video Sound Effects
```

Un clip typique de 5 secondes réalisé ainsi coûte environ **$0.024 (première image) + $0.29 (trois brouillons Wan 2.2 Spicy en 480p) + $0.45 (une version finale en 720p sur Wan 3.0) ≈ $0.76**.

**cURL :**

```bash
export SPICY_API_KEY="sk-spicy-..."   # https://spicyapi.ai/fr/console

  -H "Authorization: Bearer $SPICY_API_KEY"
```

**Python (bibliothèque standard uniquement) :**

```python
import json, os, time, urllib.request, uuid

API = "https://api.spicyapi.ai/api/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['SPICY_API_KEY']}", "Content-Type": "application/json"}

def call(method, path, body=None, extra_headers=None):
    req = urllib.request.Request(API + path, method=method, headers={**HEADERS, **(extra_headers or {})},
                                 data=json.dumps(body).encode() if body else None)
    with urllib.request.urlopen(req) as resp:
        return json.load(resp)["data"]

task = call("POST", "/jobs/createTask", {
    "model": "alibaba/wan-2.2-spicy/image-to-video",
    "input": {"image_url": "https://example.com/first-frame.jpg",
              "prompt": "She turns slowly toward the camera, silk robe slipping off one shoulder, candlelight, slow push-in.",
              "duration_seconds": 5, "resolution": "480p"},
}, {"Idempotency-Key": str(uuid.uuid4())})

while task["state"] in ("queued", "running"):
    time.sleep(5)
    task = call("GET", f"/jobs/recordInfo?taskId={task['taskId']}")

print(task["state"], task.get("output", {}).get("assets", [{}])[0].get("url"))
```

## FAQ

### Quels sont les meilleurs prompts vidéo IA NSFW pour Wan 2.2 ?
Des prompts courts, avec une seule action et un mouvement de caméra nommé : voir [Boudoir & lingerie](#boudoir--lingerie) et [Gabarits de mouvement & caméra réutilisables](#gabarits-de-mouvement--caméra-réutilisables). Wan 2.2 Spicy génère exactement 5 ou 8 secondes : écrivez donc une action par clip et utilisez `last_image_url` quand vous avez besoin d'une fin précise.

### Comment écrire un prompt image en vidéo NSFW ?
Partez d'une première image solide, puis décrivez uniquement le mouvement : une action principale, un mouvement secondaire, la caméra et la lumière. Restez entre 40 et 80 mots. Voir [Comment écrire un prompt vidéo NSFW qui fonctionne](#comment-écrire-un-prompt-vidéo-nsfw-qui-fonctionne).

### Quel est le meilleur modèle pour l'image en vidéo NSFW ?
D'après les tests de SpicyAPI : **Wan 3.0** pour le meilleur résultat polyvalent par dollar (Index 76.5, Freedom 96, tous les prompts de test explicites rendus, $0.45 les 5 s en 720p) ; **Seedance 2.5 Spicy**, **Wan 2.7 Spicy** et **Vidu Q3 Spicy** (Freedom 96.7–100) pour l'image en vidéo la moins filtrée ; **MiniMax H3 LoRA** pour vos propres styles ; **Wan 2.6 Flash** et **Seedance 1.5 Pro Spicy** pour les petits budgets. Comparez-les sur les [classements SpicyAPI](https://spicyapi.ai/fr/leaderboards?utm_source=github&utm_medium=repo&utm_campaign=2026-09-nsfw-ai-video-prompts&utm_content=faq-fr).

### Pourquoi l'anatomie est-elle ratée dans mes vidéos IA NSFW ?
En général, il y a trop de mouvement pour la durée du clip. Réduisez à 5 secondes et à une seule action, gardez les mains détendues ou hors champ, préférez les angles de côté ou de dos pour les plans en pied, et choisissez un modèle plus puissant (Seedance 2.x) pour les scènes à deux.

### Peut-on utiliser ces prompts avec Stable Diffusion ou ComfyUI ?
Oui. Les prompts de première image fonctionnent dans n'importe quel workflow SDXL, Pony ou Z-Image, et les prompts vidéo fonctionnent avec Wan 2.2 auto-hébergé dans ComfyUI. Attendez-vous à ajuster la force et le nombre d'étapes en local.

### Combien coûte la génération d'une vidéo IA NSFW ?
