| やること | やらないこと |
|---|---|

## カメラ・ライティング・動きの早見表

**カメラワーク**

| 用語 | 効果 | 安定度 |
|---|---|---|
| `static camera` / `locked-off` | カメラが動かない | 最高 |
| `slow push-in` | 被写体に向かってゆっくり寄る | 高 |
| `pull back` / `dolly out` | 引いていき、部屋全体を見せる | 高 |
| `tilt up` / `tilt down` | 体に沿って縦方向にカメラを振る | 高 |
| `tracking shot` | 被写体を横から追いかける | 中 |
| `orbit left / right` | 被写体の周りを回る | 中（Seedance が最も得意） |
| `handheld` | 自然な軽い揺れ。クリエイターが撮った映像の雰囲気 | 中 |
| `rack focus` | ピントが手前 → 被写体に移る | 中 |
| `drone descent` / `drone pull-back` | 高い位置からの大きな動き | 中 |
| `POV` | 一人称視点 | 低め |

**雰囲気別のライティング**

| 雰囲気 | 書き方 |
|---|---|
| ロマンチック | warm candlelight, golden tones, soft diffused light |
| ドラマチック | single hard key light, deep shadows, chiaroscuro |
| 幻想的 | backlit, glowing highlights, haze, bloom |
| ノワール | slatted blinds light, black and white, cigarette smoke |
| ラグジュアリー | soft beauty lighting, no harsh shadows, glossy highlights |
| ミステリアス | rim light only, face in shadow, silhouette |
| ナチュラル | window light, golden hour, soft ambient |
| ネオン | magenta and cyan neon, wet reflections, rain |

**長さの目安**

| 内容 | 長さ | 理由 |
|---|---|---|
| 呼吸、シネマグラフ | 4〜5 秒 | 動きが最小限なので画質を保てる |
| 1 つのしぐさ、振り向き | 5 秒 | はっきりした動作が 1 つ |
| 歩く、見せていく、カメラの移動 | 5〜8 秒 | 連続しているがシンプルな動き |
| ダンス、2 人のシーン | 5 秒 | 長くするほど破綻が積み重なる |

## 画像から動画へのパイプライン

```
1. First frame   → Qwen Image 2.1 (photoreal, from $0.024) or Prefect Pony XL (anime)
2. Fix details   → Qwen Image Edit Spicy (change outfit, pose, lighting with one instruction)
3. Draft motion  → Wan 2.6 Flash, Seedance 1.5 Pro Spicy or Wan 2.2 Spicy at 480p, 3–5 variations
4. Final render  → the best draft's prompt on Wan 3.0, Seedance 2.5 Spicy or Wan 2.7 Spicy at 720p–1080p
5. Extend        → Wan 2.2 Spicy LoRA video-extend, or last-frame chaining
6. Polish        → Video Upscaler, Lip Sync or Video Sound Effects
```

手順：① 開始フレームを作る（フォトリアルなら Qwen Image 2.1、アニメなら Prefect Pony XL）→ ② Qwen Image Edit Spicy で細部を直す（服装、ポーズ、ライティングを指示 1 つで変更）→ ③ Wan 2.6 Flash、Seedance 1.5 Pro Spicy、Wan 2.2 Spicy のいずれかの 480p で 3〜5 パターンの下書き → ④ いちばん良い下書きのプロンプトを Wan 3.0、Seedance 2.5 Spicy、Wan 2.7 Spicy のいずれかの 720p〜1080p で仕上げ → ⑤ Wan 2.2 Spicy LoRA の video-extend か最後のフレームをつないで延長 → ⑥ Video Upscaler、Lip Sync、Video Sound Effects で仕上げ。

この流れで 5 秒の動画を 1 本作ると、おおよそ **$0.024（開始フレーム）+ $0.29（Wan 2.2 Spicy の 480p 下書き 3 本）+ $0.45（Wan 3.0 の 720p 仕上げ 1 本）≈ $0.76** です。

```python
        return json.load(resp)["data"]

task = call("POST", "/jobs/createTask", {
    "model": "alibaba/wan-2.2-spicy/image-to-video",
    "input": {"image_url": "https://example.com/first-frame.jpg",
              "prompt": "She turns slowly toward the camera, silk robe slipping off one shoulder, candlelight, slow push-in.",
              "duration_seconds": 5, "resolution": "480p"},
}, {"Idempotency-Key": str(uuid.uuid4())})

while task["state"] in ("queued", "running"):
    time.sleep(5)
    task = call("GET", f"/jobs/recordInfo?taskId={task['taskId']}")

print(task["state"], task.get("output", {}).get("assets", [{}])[0].get("url"))
```

## LLM にプロンプトを書かせる

次のシステムプロンプトを好きなチャットモデルに貼り付けてください（SpicyAPI なら、OpenAI 互換エンドポイント経由で [Grok 4.7](https://spicyapi.ai/ja/models/grok-4-7?utm_source=github&utm_medium=repo&utm_campaign=2026-09-nsfw-ai-video-prompts&utm_content=llm-ja) や [DeepSeek V4.1 Flash](https://spicyapi.ai/ja/models/deepseek-v4-1-flash?utm_source=github&utm_medium=repo&utm_campaign=2026-09-nsfw-ai-video-prompts&utm_content=llm-ja) がよく合います）。

```text
You write prompts for adult image-to-video models. Every character is an adult; always state an age of 21 or older
and never use descriptors that suggest youth. Never depict real, identifiable people.
Given a short idea and a description of the first frame, return ONE prompt of 40–80 words that:
1) describes only what changes from the first frame, 2) has exactly one main action,
3) adds one secondary motion (hair, fabric, light, water, steam), 4) names one camera move,
5) names the light sources, 6) ends with a short style phrase. Also return a 1-line negative prompt.
```

このシステムプロンプトの内容：登場人物は全員成人とし、必ず 21 歳以上の年齢を明記して幼さを連想させる表現は使わない。実在の特定できる人物は描かない。そのうえで、開始フレームからの変化だけを書き、メインの動作は 1 つ、副次的な動きを 1 つ、カメラワークを 1 つ、光源、短いスタイル表現を含む 40〜80 語のプロンプトと、1 行のネガティブプロンプトを返させます。

## よくある質問

### Wan 2.2 で使える NSFW AI 動画プロンプトのおすすめは？
カメラワークを指定した、動作 1 つの短いプロンプトです。[ブドワール & ランジェリー](#ブドワール--ランジェリー)と[使い回せるモーション & カメラテンプレート](#使い回せるモーション--カメラテンプレート)を見てください。Wan 2.2 Spicy はちょうど 5 秒か 8 秒で出力するので、1 本につき動作は 1 つにし、特定の終わり方が必要なら `last_image_url` を使ってください。

### NSFW の画像から動画プロンプトはどう書けばいい？
しっかりした開始フレームを用意し、動きだけを書きます。メインの動作 1 つ、副次的な動き 1 つ、カメラ、光。40〜80 語に収めてください。[うまくいく NSFW 動画プロンプトの書き方](#うまくいく-nsfw-動画プロンプトの書き方)を参照してください。

### NSFW の画像から動画に最適なモデルは？
SpicyAPI のテストでは、1 ドルあたりの総合的な仕上がりで選ぶなら **Wan 3.0**（Index 76.5、Freedom 96、露骨なテストプロンプトはすべて指示どおりに生成、720p で 5 秒 $0.45）。最も露骨な画像から動画なら **Seedance 2.5 Spicy**、**Wan 2.7 Spicy**、**Vidu Q3 Spicy**（Freedom 96.7〜100）。自分のスタイルなら **MiniMax H3 LoRA**。低予算なら **Wan 2.6 Flash** と **Seedance 1.5 Pro Spicy**。[SpicyAPI のリーダーボード](https://spicyapi.ai/ja/leaderboards?utm_source=github&utm_medium=repo&utm_campaign=2026-09-nsfw-ai-video-prompts&utm_content=faq-ja)で比較できます。

### NSFW AI 動画で体の形が崩れるのはなぜ？
たいていは、動画の長さに対して動きが多すぎるのが原因です。5 秒に縮め、動作を 1 つに減らし、手はフレームの外に出すか力を抜いた状態にし、全身のショットは横や後ろからのアングルにし、2 人のシーンでは強いモデル（Seedance 2.x）を選んでください。

### このプロンプトは Stable Diffusion や ComfyUI でも使える？
使えます。開始フレーム用のプロンプトは SDXL、Pony、Z-Image のどのワークフローでも使え、動画プロンプトは ComfyUI でセルフホストした Wan 2.2 でも使えます。ローカルでは strength や steps の調整が必要になるはずです。

### NSFW AI 動画を 1 本作るのにいくらかかる？
SpicyAPI（{{READ_ON}} のカタログ）では、5 秒の動画 1 本が $0.06（Seedance 1.5 Pro Spicy、480p）や $0.095（Wan 2.2 Spicy、480p）から、最大で約 $5.40（Seedance 2.5 Spicy、1080p）です。上の各プロンプトにも、それぞれの費用を載せています。

### 無料の NSFW 動画プロンプト生成ツールはある？
上の [LLM 用システムプロンプト](#llm-にプロンプトを書かせる)を、好きなチャットモデルで使ってください。Ollama や LM Studio のローカルモデルでも使えます。
